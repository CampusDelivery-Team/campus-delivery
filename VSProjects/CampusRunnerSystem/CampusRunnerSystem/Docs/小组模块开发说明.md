# 小组模块开发说明

## 分工建议

- 前端 1：普通用户端页面，包括地址管理、发布任务、我的任务、支付记录、评价投诉。
- 前端 2：跑腿员端页面，包括任务大厅、我的接单、状态更新、我的结算。
- 前端 3：管理员端页面，包括用户管理、跑腿员审核、节点管理、服务类型、派单、退款、投诉、审计、报表。
- 后端 1：`users`、`user_addresses`、`runners`。
- 后端 2：`nodes`、`service_types`、`service_node_rules`。
- 后端 3：`tasks`、`food_delivery_details`、`express_pickup_details`、`private_task_details`。
- 后端 4：`assign_records`、`task_status_logs`，并联动 `tasks`、`runners`。
- 后端 5：`payments`、`refunds`、`reviews`、`complaints`。
- 后端 6：`settlements`、`settlement_payment_items`、`audit_logs`、`audit_status_log_checks`、`audit_payment_checks`、`audit_refund_checks`、`reports`、`report_audit_items`。
- 总集成：项目结构、Oracle 连接、公共代码、登录权限、Layout、菜单、Git 合并、联调测试、演示流程。

## 开发约定

- Controller 只负责接收请求和返回页面。
- Service 负责业务判断。
- Repository 负责数据库访问。
- View 只负责显示。
- 所有 SQL 使用参数化查询。
- 所有角色、状态、是否标志使用中文枚举值。
- 不修改 `Database/campus_runner_oracle_schema_cn.sql`，除非全组确认数据库结构变更。
