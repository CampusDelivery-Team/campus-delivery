# 项目运行说明

## 运行前检查

1. Oracle 19c 已启动。
2. PDB 服务名为 `orclpdb`。
3. campus 用户存在，密码为 `Campus123456`。
4. 24 张表已经在 campus 用户下创建。
5. `appsettings.json` 中存在 `ConnectionStrings:OracleConnection`。

## Visual Studio 运行

1. 打开 `CampusRunnerSystem.sln`。
2. 选择 `CampusRunnerSystem` 作为启动项目。
3. 按 F5 或 Ctrl+F5。
4. 浏览器进入 `/Account/Login`。

## 登录和演示

1. 输入 `admin / 123456`。
2. 登录成功后进入管理员首页。
3. 点击“节点管理”查看 `nodes` 表数据。

## 排错顺序

1. 先看 Oracle 是否启动。
2. 再看连接串是否正确。
3. 再看 campus 用户下是否存在表。
4. 再看中文枚举值是否与 SQL 文件一致。
5. 最后看 Controller、Service、Repository 的调用链。
