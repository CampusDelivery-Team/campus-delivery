# Razor Views

本目录存放 MVC Razor 页面。

当前页面：

```text
Home/Index.cshtml       # 项目主页面
Home/Error.cshtml       # 错误页
Node/Index.cshtml       # 节点列表
Node/Create.cshtml      # 新增节点
Node/Edit.cshtml        # 编辑节点
Database/Status.cshtml  # 数据库状态
Shared/_Layout.cshtml   # 共享布局
```

页面应显示中文名称。数据库英文代码的转换应由 Service/ViewModel 先准备好，View 中尽量只做展示。
