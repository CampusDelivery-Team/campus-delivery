# JiRun Brand Assets

These assets define the first visual direction for "济跑跑 / JiRun".

## Production assets

- `jirun-mark.png`: transparent high-resolution JR mark.
- `jirun-mark-512.png`: transparent app icon size.
- `jirun-mark-256.png`: transparent app icon size.
- `jirun-mark-192.png`: transparent PWA/mobile icon size.
- `jirun-mark-128.png`: transparent compact UI icon size.
- `jirun-mark-64.png`: transparent navbar/sidebar icon size.
- `jirun-mark-32.png`: transparent favicon-sized icon.
- `favicon.ico`: browser favicon candidate.

## Visual assets

- `jirun-hero-campus.png`: landing page hero visual.
- `jirun-admin-visual.png`: login/admin dashboard visual.
- `jirun-sidebar-dark.png`: dark sidebar brand reference.
- `jirun-brand-sheet.png`: presentation/documentation brand sheet.
- `jirun-horizontal-reference.png`: horizontal logo reference.

## Usage note

For the website UI, prefer using the transparent JR mark image plus real HTML text
for "济跑跑" and "JiRun". Generated logo text is useful for visual reference, but
HTML-rendered text will be sharper and more reliable in the final interface.
