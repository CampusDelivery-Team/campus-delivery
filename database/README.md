# 数据库层 Database

数据库层负责 Oracle 表结构、基础数据、测试数据和数据库说明。

当前目录：

```text
database/oracle/
```

本层应该存放：

```text
001_schema.sql
init_base_data.sql
init_test_data.sql
```

职责：

- 创建 24 张业务表。
- 维护主键、外键、唯一约束、检查约束。
- 维护中文枚举值。
- 准备管理员账号、普通用户账号、跑腿员账号、节点、服务类型、服务规则等基础数据。
- 为各业务模块提供可验证的数据环境。

注意：

- 业务代码不要直接修改数据库层脚本。
- 修改表结构前必须先和数据库负责人、总集成人员确认。
- 数据库枚举值统一使用中文，不要改成英文。
