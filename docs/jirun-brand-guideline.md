# 济跑跑 JiRun 品牌与界面说明

## 1. 品牌定位

济跑跑 JiRun 是面向同济校园场景的跑腿订单协同平台，用于连接普通用户、跑腿员和平台管理员。

产品覆盖的核心流程包括：

- 普通用户发布校园跑腿任务；
- 跑腿员在任务大厅接单并完成配送；
- 用户确认收货、支付、评价或发起退款投诉；
- 管理员进行任务调度、跑腿员审核、退款审核、结算审计和统计报表管理。

品牌表达重点是“轻快、可信、清爽、有校园感”。界面不直接使用同济大学官方校徽、校标或官方视觉系统，只表达校园跑腿和订单协同场景。

## 2. 品牌名称

- 中文名：济跑跑
- 英文名：JiRun
- 产品全称：济跑跑 JiRun - 同济校园跑腿订单协同平台
- 推荐口号：校内需求，一路送达

页面中推荐使用：

- 首页主标题：济跑跑 JiRun
- 后台名称：济跑跑运营后台
- 跑腿员端：济跑跑配送工作台
- 普通用户端：我的校园跑腿订单

## 3. Logo 方向

Logo 以 `J` 和 `R` 为核心元素：

- `J` 对应 JiRun 的首字母，也表示跑腿路径的起点；
- `R` 对应 Run，表示配送流转和完成方向；
- 左侧速度线表达“跑跑”的轻快节奏；
- 蓝绿主色表达校园、可信和服务流转；
- 橙色节点表达取件点、送达点或关键订单节点。

## 4. 颜色规范

当前界面主色建议：

- 校园蓝：`#0B4FB3`
- 活力青：`#00A6A6`
- 订单橙：`#F59E0B`
- 深海军蓝：`#0B1F3A`
- 页面背景：`#F5F8FC`
- 正文深色：`#102033`
- 次级文字：`#64748B`
- 边框灰蓝：`#DCE7F5`

使用原则：

- 主要按钮使用蓝到青的渐变；
- 成功、运行中、可用状态优先使用青绿；
- 关键节点、提醒、订单标记使用橙色；
- 危险或失败状态保留红色；
- 避免继续扩大旧版粉紫色的使用范围。

## 5. 页面改版范围

当前已经完成的第一版品牌化改动：

- 全局浏览器标题改为“济跑跑 JiRun”；
- 顶部导航品牌区使用 JR 图标和“济跑跑 / JiRun Campus Service”；
- 首页首屏改为济跑跑产品定位和校园路线视觉；
- 首页角色入口改为普通用户、跑腿员、管理员的真实工作流；
- 登录页和注册页加入品牌图标与运营视觉；
- 全局基础样式新增济跑跑品牌色、按钮、卡片、首页和登录页视觉覆盖。

后续可继续优化的地方：

- 旧页面中残留的粉紫色状态或装饰色；
- 管理员后台下拉菜单可以进一步升级为侧边栏；
- 表格、表单、状态标签可以继续统一成同一套组件风格；
- 任务、支付、退款、结算、审计页面可以逐页做细节抛光；
- 移动端导航可以单独优化。

## 6. 后续修改原则

后续改页面时建议遵循：

- 不再新增无意义的大面积粉紫渐变；
- 不使用官方同济校徽或校标；
- 不把生成图片中的文字直接当作主要页面文字；
- 业务页面优先保证信息密度、表格可读性和操作清楚；
- 首页、登录页可以更有视觉感，后台页面应保持清爽、克制、稳定。
