## 3. 完成标准

证据包只有在 `01-screenshot-index.md` 中所有核心流程均标记为 `PASS`，且每个涉及数据变化的流程同时具备页面截图和 SQL 查询结果时，才可对外称为“完整”。`PASS-READONLY` 和 `PARTIAL` 均不等同于本次端到端执行通过。

每张截图必须满足：

1. 文件名与索引编号一致。
2. 页面中能看到功能名称、关键状态或成功提示。
3. 隐藏密码、连接串、手机号、身份证号等敏感信息。
4. 涉及写操作时，附对应 SQL Developer 查询结果。
5. 失败截图必须登记缺陷编号，不能作为通过证据。
