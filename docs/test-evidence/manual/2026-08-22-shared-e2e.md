### 5.2 负向和安全边界

以下实际提交均未产生越权或重复数据：

- 重复用户名、重复手机号、空字段和非法注册格式。
- 错误密码、封禁账号、注销账号、未登录业务页和 USER 管理页访问。
- 缺失 Anti-forgery Token 的 POST 返回 400。
- 跨用户编辑/删除地址、使用他人地址发布任务、不存在地址 ID。
- 重复跑腿员申请、不合格或离线跑腿员接单、忙碌跑腿员抢第二单。
- 停用服务、关闭节点、管理员派给不合格跑腿员、重派给当前跑腿员。
- 非当前跑腿员更新配送状态、非法状态跳转、不存在任务 ID。
- 非发布者确认收货、非法支付方式、重复支付、退款后再次支付。
- 未付款评价、重复评价、非法评分、超长评价。
- 重复退款申请、重复投诉、跨用户投诉、重复处理已办结投诉。
- 争议款进入结算、重复结算、`DONE -> WAITING` 回退。
- 空审计目标、重复审计目标、非法报表类型/周期、极端分页和注入式查询文本。
